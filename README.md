# 수시모집 경쟁률 현황 확인 및 일자별 엑셀 누적기록 웹 앱

본 웹 애플리케이션은 **국립군산대학교**와 **원광대학교**의 수시모집 지정 4개 학과전형의 실시간 경쟁률을 크게 확인하고, 버튼 클릭 한 번으로 일자별·시간대별 현황을 엑셀 시트에 계속 아래로 누적 기록 및 저장해주는 웹 프로그램입니다.

---

## 📌 주요 추적 4개 학과 및 전형 목록

1. **국립군산대학교** | 학생부종합전형 일반학생 - **미디어문화학부** (모집 14명 / 지원 27명 / 경쟁률 1.93 : 1)
2. **국립군산대학교** | 학생부교과 지역인재 1 - **자율전공학부** (모집 42명 / 지원 67명 / 경쟁률 1.60 : 1)
3. **국립군산대학교** | 학생부교과 일반전형 - **무역학과** (모집 14명 / 지원 21명 / 경쟁률 1.50 : 1)
4. **원광대학교** | 학생부교과 일반전형 - **창의문화융합계열** (모집 32명 / 지원 49명 / 경쟁률 1.53 : 1)

---

## 🚀 사용법 (실행 방법)

1. `index.html` 파일을 크롬(Chrome), 엣지(Edge) 등 브라우저로 더블 클릭하여 실행합니다.
2. 메인 상단의 **`[ 🔍 경쟁률 확인하기 & 엑셀 누적 기록 ]`** 버튼을 누릅니다.
3. 현재 날짜와 시각(일자별/시간별)을 기준으로 4개 영역의 모집인원, 지원인원, 경쟁률이 화면 카드 및 종합 표에 반영됩니다.
4. **자동 엑셀 저장**: 경쟁률 확인 시 일자별/시간별로 데이터가 누적 기록된 엑셀 파일(`.xlsx`)이 자동으로 다운로드됩니다.
5. **기존 엑셀 파일 이어 쓰기**: `[ 📂 기존 엑셀 불러오기 ]` 버튼을 사용하면 이전에 저장해 두었던 엑셀 파일을 업로드하여 그 아래에 지속적으로 새 기록을 누적(Append)시킬 수 있습니다.

---

## 🛠️ 주요 기능 요약

- **대형 가독성 카드**: 4개 지정 학과전형 경쟁률을 큰 글씨로 직관적으로 표시.
- **4개 영역 종합 표**: 모집인원, 지원인원, 경쟁률, 확인일시 정리.
- **일자별/시간별 연속 누적 시트**: 브라우저 `localStorage` 및 엑셀 시트에 지속적인 히스토리 기록 보존.
- **독립 실행 가능**: 별도 서버 설치 없이 `index.html` 파일 단독 구동.
